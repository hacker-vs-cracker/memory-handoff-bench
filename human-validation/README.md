# Human validation

This directory contains publication-safe derivatives of the completed independent
human validation.

- Reviewer A and Reviewer B independently reviewed the blinded W/I material.
- W raw agreement: 44/48 (91.67%); Cohen's kappa approximately 0.317.
- I raw agreement: 188/192 (97.92%); Cohen's kappa approximately 0.944.
- Eight independent-review disagreements were adjudicated after the original
  judgments were locked.
- The executed-attack casebook contains 114 reviewed rows; the previously unresolved
  deep-evidence rows were subsequently checked before closeout.
- Registered machine W/I labels remain the primary benchmark outcomes. Human
  judgments are validation/sensitivity evidence and did not rewrite registered
  database outcomes.

Raw reviewer returns, identity/mapping material, personal names, and sealed raw-review
packages are intentionally not distributed in this repository.
