# v0.2.4 frozen-source provenance

The retained local publication ZIP contains the v0.2.4 protocol lock and publication
summaries, but the physical archive on this workstation does not contain the
`reproducibility/frozen-protocol/` subtree described by historical documentation.

For this public artifact, the source tree is reconstructed only from the files
enumerated in `protocol_lock-v0.2.4.json` in the preserved historical repository.
Every copied file is SHA-256 checked against that lock. The collector aborts if any
file is absent or differs.

This is a packaging-layout repair only. No registered trial, registered result,
database row, model output, or protocol identity is modified.
